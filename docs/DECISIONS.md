# 設計判断

この文書には現在の製品設計を理解するために必要な判断だけを残す。実装途中の
マイルストーン、廃止済みTUI、完了済み調査の時系列記録は保持しない。

## D-001: エンコード境界はチャプター番号だけを使う

- HandBrakeCLIへ`--chapters N-M`を渡し、秒・フレーム・PTS指定を使わない。
- HandBrake GUIでも生じる素材依存の境界重複・欠落は同等挙動として許容し、
  自動補正や事後トリミングを行わない。

## D-002: キュー先頭を成功まで残す

- ジョブはエンコード、title設定、検証、最終公開、キュー保存がすべて成功した後だけ
  `queue.json`から削除する。
- 失敗または即時中断では先頭を残し、後続を実行しない。

## D-003: titleは最終出力名から導出する

- DLNA表示用titleは最終出力ファイル名のstemに固定し、キューへ重複保存しない。
- MKVは`mkvpropedit`でtitleだけを直接変更する。
- MP4はFFmpegのストリームコピーでtitleを変更し、映像・音声を再エンコードしない。
- title設定と構造検証が完了するまで最終ファイル名へ公開しない。

## D-004: 音声はTrackごとの三状態とする

- 解析できた全入力Trackについて、高音質・低音質・未選択を一つ選ぶ。
- 先頭Trackは高音質、2番目以降は低音質を初期値とする。
- 高音質は安全ならAC-3をパススルーし、それ以外は高音質AACへ変換する。
- 低音質はAAC 160 kbps stereoへ変換する。
- 全未選択を許可し、HandBrakeCLIへ`--audio none`を明示する。

## D-005: 字幕焼き付けを常に無効化する

- MKVは選択字幕をソフト字幕として格納できる。
- MP4は字幕なしとする。
- プリセット由来の自動字幕、Foreign Audio Search、焼き付けを明示的に上書きする。

## D-006: GUIエクスポートプリセットを明示ファイルとして読む

- `~/Documents/ChapterBrake/My Presets.json`を最初のプリセット一覧に使う。
- HandBrake GUIの内部設定と`--preset-import-gui`には依存しない。
- ファイルがない場合だけ、GUI相当の内蔵4件を互換フォールバックとして使う。
- `My Old Presets`と`GCCX`のクロップ差を維持する。

## D-007: 入出力先と区切り時間を設定に持つ

- 既定入力先は`/Volumes/2TB HDD/Images`、既定出力先は
  `/Volumes/2TB HDD/Movies`、既定区切り時間は`23:40`とする。
- `--directory` / `-d`は一回の起動だけ入力開始位置を上書きする。
- チャプター画面で変更した区切り時間は、そのドラフトだけに適用する。
- 最終出力と処理中一時ファイルは`<output_directory>/<ベース名>/`へ置く。

## D-008: 自動分割の短い末尾を明示的に扱う

- 2秒以下の最終チャプターは初期状態で除外し、利用者が解除できる。
- 区切り時間近似で短い末尾単独出力が生じる場合は直前区間へ結合し、画面先頭で
  通知する。
- ほぼ一話分の末尾は独立区間として残す。

## D-009: ファイル一覧は固定の名前昇順にする

- `../`を先頭へ固定し、それ以外のディレクトリとMKVを混在させたまま、
  大文字小文字を区別しない名前昇順で表示する。
- 更新時刻順や利用者切替式のソートは設けない。

## D-010: Web UIだけを製品フロントエンドとする

- 廃止済みTUIとは共存しない。
- 独立したトップ画面とキュー一覧画面を作らず、入力手順、現在手順、常設右キューの
  三領域を使う。
- キュー詳細と設定はモーダルで開く。
- 待機ジョブの並び替えには同梱したSortableJSを使う。

## D-011: 汎用サーバーとアプリ固有UIを分離する

- Local Web App Serverは静的配信、Unixソケット中継、プロセス管理を担う。
- ChapterBrakeはアプリ固有のHTML/CSS/JavaScriptとAPIを所有する。
- SortableJSを含むUIライブラリはChapterBrake側でバージョン固定する。

## D-012: 信頼済みLANから操作可能にする

- 汎用サーバーは既定で`0.0.0.0:8766`を待ち受ける。
- TLS、HTTP認証、インターネット公開は対象外とする。
- LAN側ブラウザは指示と表示だけを行い、解析とエンコードはサーバーMac上で行う。

## D-013: 中断と一時停止を分ける

- HandBrakeのエンコード一時停止・再開は専用プロセスグループへの
  `SIGSTOP` / `SIGCONT`で行う。
- 通常終了は現在ジョブを完了してから残りを停止する。
- 即時中断はプロセスグループを終了し、部分出力を削除して先頭ジョブを残し、
  キューを一時停止する。

## D-014: 二重起動を拒否する

- 同じユーザーデータを扱うChapterBrakeはadvisory lockにより一プロセスだけ起動する。
- 複数ブラウザからの表示・操作は同じバックエンドへ接続する。
- Web構成ではLocal Web App Serverがアプリごとに一つのバックエンドを起動する。
  ChapterBrakeのlockはTUI時代のプロセス管理を継続するためではなく、ホスト障害時にも
  `queue.json`とエンコードの重複を防ぐ最終防護として単純な`flock`のまま維持する。
- 孤立プロセスのPID探索やlockファイル削除はChapterBrakeで行わない。汎用サーバーが
  渡すライフタイムFDのEOFを親ホスト異常終了の通知とし、ChapterBrakeは既存の
  即時中断経路で現在ジョブと部分出力を処理して終了する。

## D-015: ログはmacOS標準ログ領域へ置く

- 診断ログは`~/Library/Logs/ChapterBrake/`へ保存し、iCloud同期対象のDocumentsへ
  置かない。
- 外部コマンドのstdout/stderrはジョブごとの正本ログとして保持する。
