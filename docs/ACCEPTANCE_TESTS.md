# 受け入れ条件

## 0. 実装開始条件

完成アプリの受け入れ試験とは別に、実装前に`docs/POC_GATE.md`を完了する。

- `docs/POC_RESULT.md`の最終判定が`GO`である。
- チャプター、音声、字幕非焼き付け、プリセット、タイトルメタデータ後処理、即時中断の必須PoC証拠が揃っている。
- `GO WITH CHANGES`や未確認項目が残る状態で製品実装を開始していない。

## A. 起動と保存場所

- 初回起動で`~/Documents/ChapterBrake/`、`settings.json`、`queue.json`、`logs/`が作成される。
- `settings.json`の既定出力先が`/Volumes/2TB HDD/mp4/`。
- 不正な設定JSONを勝手に上書きしない。

## B. ファイル選択

- 起動ディレクトリから開始する。
- ディレクトリとMKVだけを表示する。
- MKVの容量を表示する。
- 子へ入り、親へ戻れる。
- 一覧表示だけでは各MKVのメディア解析を実行しない。
- 空白、日本語を含むパスを選択できる。

## C. チャプター

- チャプター一覧へ番号、絶対時刻、相対経過、タイトルが表示される。
- 初期表示で23分40秒近似の開始位置が選択される。
- チェック変更直後に相対経過が再計算される。
- チャプター1のチェックを外せる。
- 全解除できる。
- 0件ではプレビューへ進めない。
- 選択`1,6,14,18`、最終24から`1-5,6-13,14-17,18-24`が生成される。
- 選択`3,9,17`、最終24から`3-8,9-16,17-24`が生成され、1-2が除外表示される。
- HandBrakeCLI引数に時間指定が含まれず、チャプター指定だけが含まれる。
- 境界へ秒・フレーム・PTS補正やエンコード後トリミングを加えない。
- HandBrake固有の境界挙動は、同じ条件のHandBrake GUI出力と同等であれば許容する。

## D. 出力名

- 入力ファイルのstemが初期ベース名になる。
- 最低2桁ゼロ埋め。
- 同名の完成ファイルと待機キューを考慮し、次の開始番号を初期表示する。
- 開始番号を手動変更できる。
- 選択プリセットに応じて`.mp4`または`.mkv`になる。
- titleの期待値が各出力ファイル名のstemとしてプレビューされる。

## E. 音声

- トラック1の初期値が有効。
- トラック2が存在する場合も初期値が有効。
- トラック1・2を独立して無効にできるが、全解除では次へ進めない。
- 各選択入力トラックから、高品質と標準品質の2音声が生成される。
- 高品質パススルー非対応時も、ChapterBrakeのAACフォールバックを明示して
  高品質音声が残る。
- 音声ビットレートの数値入力は表示しない。
- トラック3以降は初期版で誤ってエンコード対象にならない。
- 生成されたファイルの音声トラック数、入力との対応、コーデック、チャンネルが
  実ファイル確認で一致する。

## F. 字幕

- MKVでは字幕なしまたは複数字幕を選べる。
- MP4では字幕画面を出さず、字幕なしになる。
- どのケースでも字幕が映像へ焼き付かない。
- プリセットに字幕自動選択が含まれていても明示設定が優先される。

## G. タイトルメタデータ

- HandBrakeCLIは最終出力名ではなくジョブ固有の隠し一時ファイルへ出力する。
- MKVはmkvpropeditでtitleをファイル名のstemへ設定する。
- MKVの後処理でFFmpeg再多重化を行わない。
- MP4はffmpegのストリームコピーでtitleをファイル名のstemへ設定する。
- MP4の映像・音声を再エンコードしない。
- 日本語、空白、記号を含むtitleを正しく設定できる。
- ffprobe等で期待titleを確認してから最終名へrenameする。
- MKV/MP4とも、後処理前後で必要な映像、音声、字幕、チャプターが維持される。
- PoCで定めた比較方法により、品質変化や説明不能な音ズレがない。
- 完成MKV/MP4をVLCで直接開き、ファイル名のstemが表示タイトルになる。
- タイトル設定失敗時は最終名を公開せず、先頭ジョブを残して停止する。

## H. プレビューと既存ファイル

- 出力ファイル数、全出力名、チャプター範囲、音声、字幕を確認できる。
- 既存出力をすべて警告表示する。
- 承認しなければキューへ追加されない。
- 承認して追加したジョブは、実行時に既存出力を再確認せず上書きする。

## I. キュー

- 複数回のアプリ起動をまたいでジョブが残る。
- 配列順に一件ずつ実行する。
- 実行中の先頭ジョブがJSONに残る。
- 成功後だけ先頭ジョブが削除される。
- 失敗時は先頭ジョブが残り、後続を実行しない。
- 不正なqueue.jsonを勝手に修復・上書きしない。

## J. 即時中断

- 実行中に即時中断できる。
- 実行中のHandBrakeCLI、ffmpeg、mkvpropeditの該当プロセスが終了する。
- エンコード用・メタデータ用の一時出力と不完全な最終出力が削除される。
- キュー先頭が残る。
- 後続ジョブが開始されない。
- 再実行すると同じ先頭ジョブを最初から実行する。

## K. ログ

- アプリログが作成される。
- 各ジョブの生ログが作成される。
- 実行ファイル、引数、入力、出力、開始、終了、終了コードが記録される。
- 失敗・中断の理由とログパスがTUIに表示される。
- HandBrakeCLI、mkvpropedit、ffmpeg、ffprobeの診断出力とタイトル検証結果がログで確認できる。

## L. Go品質

次が成功する。

```sh
gofmt -w .
go test ./...
go test -race ./...
go vet ./...
go build ./...
```

- テストが実利用の巨大MKVを常時必要としない。
- 外部コマンド引数がシェル連結されていない。
- 主要ロジックがTUIから分離されている。
