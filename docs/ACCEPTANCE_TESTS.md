# 受け入れ条件

## 0. 実装開始条件

完成アプリの受け入れ試験とは別に、実装前に`docs/POC_GATE.md`を完了する。

- `docs/POC_RESULT.md`の最終判定が`GO`である。
- チャプター、音声、字幕非焼き付け、プリセット、タイトルメタデータ後処理、即時中断の必須PoC証拠が揃っている。
- `GO WITH CHANGES`や未確認項目が残る状態で製品実装を開始していない。

## A. 起動と保存場所

- 初回起動で`~/Documents/ChapterBrake/`、`settings.json`、`queue.json`、
  `state.json`と`~/Library/Logs/ChapterBrake/`が作成される。
- 二つ目のChapterBrakeは単一起動ロックで拒否され、一つ目のキューを変更しない。
- `settings.json`の既定入力先が`/Volumes/2TB HDD/Images`。
- `settings.json`の既定出力先が`/Volumes/2TB HDD/Movies`。
- version 1設定は既存出力先を維持し、既定入力先と区切り時間を追加して
  version 4へ移行する。
- version 3の旧既定出力先だけ新既定値へ移行し、変更済み出力先は維持する。
- 不正な設定JSONを勝手に上書きしない。

## B. ファイル選択

- 通常起動では`settings.json`の`input_directory`から開始する。
- `--directory PATH`と`-d PATH`では指定ディレクトリから開始し、設定を書き換えない。
- `-d .`ではカレントディレクトリから開始する。
- 存在しないパスまたは通常ファイルをディレクトリとして指定するとエラーで停止する。
- ディレクトリとMKVだけを表示する。
- MKVの容量を表示する。
- 子へ入り、親へ戻れる。
- 一覧表示だけでは各MKVのメディア解析を実行しない。
- 空白、日本語を含むパスを選択できる。
- `../`を先頭へ固定し、残りを大文字小文字を区別しない名前昇順で表示する。
- 一覧を`↑` / `↓`で移動し、`→`で決定できる。
- `../`の決定で親ディレクトリへ移動でき、`←`では親へ移動しない。
  `Backspace` / `Esc`でメインメニューへ戻れる。

## B-2. 共通キー操作

- フォーム項目を`↑` / `↓`で移動でき、従来の`Tab`操作も使える。
- 一覧では`→`で決定し、`←` / `Backspace`で前画面へ戻れる。
- チャプター、音声、字幕のチェックを`←` / `→`または`Space`で切り替えられる。
- チェック項目上の`Enter`はチェックを変更せず、「次へ」を実行する。
- 出力ベース名と開始番号の入力欄では、`Enter`一回でチャプター画面へ進める。
- 文字列・数値入力中は`←` / `→`でカーソル移動し、`Backspace`で文字を削除できる。
- 入力欄以外の`Backspace`は一つ前の画面へ戻る。
- キュー追加中は、どの設定画面でも`Esc`一回でメインメニューへ戻れる。

## C. チャプター

- 動画全体時間と、チャプター一覧へ番号、絶対開始、単体時間、選択開始位置からの
  出力合計時間、タイトルが表示される。
- `settings.json`の既定値が`chapter_interval: "23:40"`。
- version 2設定は入出力先を維持し、既定区切り時間を追加してversion 4へ移行する。
- 初期表示で設定した区切り時間近似の開始位置が選択される。
- チャプター分割画面で区切り時間を変更でき、入力欄のEnterまたは近似選択ボタンで
  新しい値による開始位置が再選択される。
- 区切り時間入力欄のEnterでは再選択後に音声画面へ進む。
- 画面で変更した区切り時間は`settings.json`へ書き戻されない。
- 不正形式、0秒、秒が60以上の区切り時間では次へ進めない。
- チェック変更直後に出力合計時間が再計算される。
- チャプター1のチェックを外せる。
- 全解除できる。
- 0件ではプレビューへ進めない。
- 選択`1,6,14,18`、最終24から`1-5,6-13,14-17,18-24`が生成される。
- 選択`3,9,17`、最終24から`3-8,9-16,17-24`が生成され、1-2が除外表示される。
- 最終チャプターが2秒以下なら末尾除外が初期オンになり、生成範囲の終端が一つ前になる。
- 2秒を超える最終チャプターと単一チャプターでは末尾除外を自動オンにしない。
- 末尾除外を解除、または最終チャプターを手動チェックすると最終チャプターを含める。
- 自動近似で7秒などの短い末尾単体出力を直前区間へ結合し、画面先頭に通知する。
- ほぼ一話分の最終チャプターは独立した開始位置として維持する。
- 実データ相当の全長1:34:45・21チャプターでは、23:40近似が`1,7,13,19`となり、
  最終区間がChapter 19-21の約23:41になる。
- HandBrakeCLI引数に時間指定が含まれず、チャプター指定だけが含まれる。
- 境界へ秒・フレーム・PTS補正やエンコード後トリミングを加えない。
- HandBrake固有の境界挙動は、同じ条件のHandBrake GUI出力と同等であれば許容する。

## D. 出力名

- 入力ファイルのstemが初期ベース名になる。
- 最低2桁ゼロ埋め。
- 同名の完成ファイルと待機キューを考慮し、次の開始番号を初期表示する。
- 開始番号を手動変更できる。
- 選択プリセットに応じて`.mp4`または`.mkv`になる。
- titleの期待値が各出力ファイル名のstemとしてプレビューされる。
- `<output_directory>/<ベース名>/`が出力先となり、既存ディレクトリを再利用する。
- ベース名ディレクトリはキュー追加時には作られず、ジョブ実行開始時に作られる。

## E. 音声

- トラック1の初期値が有効。
- トラック2が存在する場合も初期値が有効。
- トラック1・2を独立して無効にできるが、全解除では次へ進めない。
- 各選択入力トラックから、高品質と標準品質の2音声が生成される。
- 高品質パススルー非対応時も、ChapterBrakeのAACフォールバックを明示して
  高品質音声が残る。
- 音声ビットレートの数値入力は表示しない。
- トラック3以降は初期版で誤ってエンコード対象にならない。
- 生成されたファイルの音声トラック数、入力との対応、コーデック、チャンネルが
  実ファイル確認で一致する。

## F. 字幕

- MKVでは字幕なしまたは複数字幕を選べる。
- MP4では字幕画面を出さず、字幕なしになる。
- どのケースでも字幕が映像へ焼き付かない。
- プリセットに字幕自動選択が含まれていても明示設定が優先される。

## G. タイトルメタデータ

- HandBrakeCLIは最終出力名ではなくジョブ固有の隠し一時ファイルへ出力する。
- MKVはmkvpropeditでtitleをファイル名のstemへ設定する。
- MKVの後処理でFFmpeg再多重化を行わない。
- MP4はffmpegのストリームコピーでtitleをファイル名のstemへ設定する。
- MP4の映像・音声を再エンコードしない。
- 日本語、空白、記号を含むtitleを正しく設定できる。
- ffprobe等で期待titleを確認してから最終名へrenameする。
- MKV/MP4とも、後処理前後で必要な映像、音声、字幕、チャプターが維持される。
- PoCで定めた比較方法により、品質変化や説明不能な音ズレがない。
- 完成MKV/MP4をVLCで直接開き、ファイル名のstemが表示タイトルになる。
- タイトル設定失敗時は最終名を公開せず、先頭ジョブを残して停止する。

## H. プレビューと既存ファイル

- 出力ファイル数、全出力名、チャプター範囲、音声、字幕を確認できる。
- 既存出力をすべて警告表示する。
- 承認しなければキューへ追加されない。
- 承認して追加したジョブは、実行時に既存出力を再確認せず上書きする。

## I. キュー

- 複数回のアプリ起動をまたいでジョブが残る。
- 配列順に一件ずつ実行する。
- 実行中の先頭ジョブがJSONに残る。
- 成功後だけ先頭ジョブが削除される。
- 失敗時は先頭ジョブが残り、後続を実行しない。
- 不正なqueue.jsonを勝手に修復・上書きしない。
- Enterで待機ジョブ詳細を開き、削除ボタンの確認後にジョブを削除できる。
- 実行中の先頭ジョブは削除できない。
- 矢印キーは選択だけを移動し、`j`/`k`を連続入力すると待機ジョブが一段ずつ
  下／上へ移動して永続化される。
- キュー追加直後に、一時停止中でなければ実行が始まる。
- キュー追加後は同じ入力ディレクトリのファイル選択へ戻り、連続登録できる。
- 実行中に追加したジョブが失われず、現在ジョブの後続として実行される。
- キュー一覧の実行中行へ段階、進捗、ETAが表示される。
- キュー一覧と詳細へ各ジョブの参考動画時間が表示され、実績が得られた後は
  全キューの概算ETAが表示される。
- メイン画面にも選択不能なキュー概要が表示される。
- 実行中ジョブ詳細からHandBrakeエンコードを一時停止・再開できる。
- 実行中ジョブ詳細から現在ジョブ完了後の一時停止を予約・取り消しできる。
- 一時停止後にアプリを終了・再起動し、残りの先頭ジョブから再開できる。
- 実行中の通常終了は確認後、現在ジョブを完了して残りを一時停止してから終了する。
- 通常失敗または実行中のまま前回終了した状態では、メインとキュー画面の枠が赤くなる。

## J. 即時中断

- 実行中に即時中断できる。
- 実行中のHandBrakeCLI、ffmpeg、mkvpropeditの該当プロセスが終了する。
- エンコード用・メタデータ用の一時出力と不完全な最終出力が削除される。
- キュー先頭が残る。
- キューが一時停止状態になる。
- 後続ジョブが開始されない。
- 再実行すると同じ先頭ジョブを最初から実行する。

## K. ログ

- アプリログが作成される。
- 各ジョブの生ログが作成される。
- 実行ファイル、引数、入力、出力、開始、終了、終了コードが記録される。
- 失敗・中断の理由とログパスがTUIに表示される。
- HandBrakeCLI、mkvpropedit、ffmpeg、ffprobeの診断出力とタイトル検証結果がログで確認できる。
- ログが`~/Library/Logs/ChapterBrake/`へ保存され、DocumentsのiCloud同期対象に
  新規ログを作らない。

## L. Go品質

次が成功する。

```sh
gofmt -w .
go test ./...
go test -race ./...
go vet ./...
go build ./...
```

- テストが実利用の巨大MKVを常時必要としない。
- 外部コマンド引数がシェル連結されていない。
- 主要ロジックがTUIから分離されている。
