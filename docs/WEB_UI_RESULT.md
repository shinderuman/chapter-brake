## 5. 検証中に修正した問題

- キュー追加処理の中からbusy状態のファイル読込を再入していたため、
  追加後画面が更新されない問題を解消した。
- 出力ベース名と区切り時間のEnterを明示的な`requestSubmit()`へ統一した。
- ブラウザ差で`method="dialog"`の暗黙submitが発火しない場合に備え、
  ダイアログを明示的に閉じる操作へ変更した。
- 失敗していない待機ジョブへ失敗ログを表示する条件を修正した。
- 失敗したキュー先頭を「待機」ではなく「異常停止」と表示するようにした。
