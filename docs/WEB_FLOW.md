# Web画面フロー

## 基本方針

- Google ChromeとMicrosoft Edgeのデスクトップ版を対象にする。
- マウスとブラウザ標準キーボード操作の両方を利用できる。
- Web画面、API接続、SSE接続の終了は、バックエンドのキュー実行を停止しない。
- 日本語、空白、記号を含むパスとファイル名を安全に表示する。
- 検索、テーマ、モバイル専用画面は追加しない。
- 危険な操作と上書きは画面内で明示確認する。

## 1. 全体構成

独立したトップ画面とキュー一覧画面は作らない。起動直後から入力MKV選択を表示し、
左の手順ペイン、中央の現在手順、右の実行キューペインへ分割する。
左の現在手順と完了済み手順はクリック可能とし、完了済み手順を押すと途中画面を
経由せず直接戻る。未到達の手順は操作できない。

右キューペインには全体ETA、画面内に収まるジョブ概要、現在進捗を表示する。
現在ジョブの一時停止・再開、現在ジョブ後停止、即時中断、待機ジョブ削除を直接
操作できる。待機ジョブは同梱したSortableJSでドラッグして位置指定並び替えする。
現在ジョブはドラッグできず、待機ジョブを現在ジョブより前へ移動できない。

ジョブ本体を押すと詳細モーダルを開く。設定ボタンは設定モーダルを開き、入力先、
出力先、標準区切り時間を編集して`settings.json`へ保存する。設定は新規ドラフトから
反映し、作成済みドラフトの出力先と標準区切り時間は作成時の値を保持する。

バックエンド失敗または前回異常終了がある場合は、画面上端へ赤い警告を表示する。

## 2. 入力MKV

`settings.json`の`input_directory`から開始し、ディレクトリと通常MKVだけを
名前昇順で表示する。`../`を先頭に置き、ファイルには容量を表示する。
一覧表示だけではメディア解析を行わない。

ディレクトリを押すとそのディレクトリへ移動し、MKVを押した時点で一度だけ解析する。
解析中はHandBrakeCLIのスキャン進捗を取得し、スピナーと0〜100%の進捗バー・数値を
表示する。不定進捗の折り返し表示にはしない。
親移動専用の左キー操作は作らない。

## 3. プリセット

最初に`My Presets.json`のプリセット、または互換フォールバック4件を表示する。
「その他のプリセットから選ぶ」を押した場合だけHandBrake標準プリセットを表示する。
MP4/MKV以外または形式不明はAPIが選択時に拒否する。

## 4. 出力名

出力ベース名と開始番号を編集する。形式と出力例は読み取り専用で表示する。
出力ベース名または開始番号の入力中にEnterを押すと次へ進む。

## 5. チャプター

区切り時間、動画全体時間、末尾除外、末尾結合通知を先に表示する。一覧列は次とする。

- 選択
- 番号
- 絶対開始
- 単体時間
- 選択開始位置からの出力合計
- タイトル

区切り時間入力中のEnterは現在値を保存して次へ進む。近似値ボタンは同じ画面で
選択開始位置を再計算する。全解除後に次へ進むとAPIが拒否する。

## 6. 音声

すべての入力音声トラックについて、高音質・低音質・未選択から一つを選択する。
先頭トラックは高音質、2番目以降は低音質を初期値とする。数値ビットレート入力は
作らない。全トラックを未選択にした場合は、音声なしとして次へ進める。

## 7. 字幕

MKVだけ表示する。「字幕を入れない」とソフト字幕トラックを選択でき、
トラックを選ぶと「字幕を入れない」は解除される。焼き付けは常に無効と表示する。
MP4はこの画面を省略し、空字幕配列を使用する。

## 8. プレビュー

全出力名、チャプター範囲、参考時間、音声、字幕、字幕焼き付けなしを表示する。
既存出力が一つでもある場合は全件を表示し、上書きチェックを承認しない限り
キューへ追加できない。

追加成功後はキューを自動開始し、キュー一覧ではなく同じ入力ディレクトリへ戻る。

## 9. 右キューペイン・ジョブ詳細

右キューペインには全体ETA、各出力名、状態、参考時間、チャプター範囲を表示する。
現在ジョブには段階と進捗も表示する。ジョブを押すと詳細を開く。

現在ジョブ詳細:

- HandBrake段階のエンコード一時停止・再開
- 現在ジョブ後停止の予約・取消
- 確認後の即時中断とキュー一時停止
- 現在ログの差分表示

待機ジョブ:

- 右ペインのドラッグ＆ドロップによる位置指定移動
- 右ペインまたは詳細モーダルから確認後の削除

実行中先頭は移動・削除できず、待機ジョブをその前へ移動できない。

## 10. 再読み込みと終了

ブラウザを再読み込みまたは終了してもエンコードは継続する。再度開くとAPIとSSEの
完全スナップショットから現在状態を復元する。SSE切断中は再接続中と表示し、
復旧後に最新状態へ置き換える。

Local Web App ServerまたはChapterBrakeバックエンドの通常終了では、
一時停止中のHandBrakeを再開し、現在ジョブ完了後に残りを一時停止して終了する。
利用者が行う即時中断はWeb UIの専用操作だけとする。Local Web App Serverが異常終了し、
継承ライフタイムFDがEOFになった場合も、孤立バックエンドを残さないため同じ即時中断
経路で部分出力を削除して終了する。
