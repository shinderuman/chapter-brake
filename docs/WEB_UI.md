# ChapterBrake Web UI

## 1. 役割

ChapterBrakeのWeb UIは、汎用Local Web App Serverから配信される
アプリ固有のHTML/CSS/JavaScriptである。汎用サーバーの画面やCSSを共有せず、
ChapterBrakeの既存ユースケースを`docs/WEB_API.md`のAPIへ接続する。

設定ファイルの編集、任意コマンド実行、HandBrakeCLI引数編集は提供しない。
デスクトップ版Google ChromeとMicrosoft Edgeを対象とし、モバイル表示は対象外とする。

## 2. 画面

- メイン
  - 新規ジョブ追加
  - キュー件数、実行状態、全体ETA
  - 右側に全キュー概要と現在進捗
  - 異常停止時は画面上端に赤い警告
- ジョブ追加
  - サーバー側入力ファイル選択
  - My PresetsまたはHandBrake標準プリセット選択
  - 出力ベース名と開始番号
  - 区切り時間、チャプター開始位置、末尾除外
  - 音声、MKVソフト字幕
  - 出力プレビューと既存出力の上書き承認
- キュー・実行状況
  - 全ジョブの参考動画時間、チャプター範囲、現在段階、進捗
  - ジョブ詳細、ログ
  - エンコード一時停止・再開
  - 現在ジョブ後停止
  - 即時中断してキュー一時停止
  - 待機ジョブの一段移動と削除

ジョブ追加成功後は同じ入力ディレクトリへ戻り、エンコードを継続しながら
次のジョブを連続登録できる。キュー一覧へは自動遷移しない。

## 3. 入力と確認

- Tab、Shift+Tab、矢印キーなどブラウザ標準のキーボード操作を維持する。
- 出力ベース名と区切り時間の入力欄ではEnterを「次へ」として扱う。
- 必須値と区切り時間形式はHTML制約で入力欄に表示し、APIの構造化エラーは
  現在画面を維持して通知する。
- 既存出力の上書きはチェックによる明示承認を必須にする。
- 待機ジョブ削除と即時中断は、アプリ内の確認ダイアログを必須にする。

## 4. 状態更新

- 初期表示は`GET /api/status`と`GET /api/queue`から構築する。
- 以後は`GET /api/events`の完全スナップショットとログ差分で更新する。
- SSE切断中は「再接続中」と表示し、自動再接続後の完全スナップショットで復元する。
- ブラウザ再読み込み、タブを閉じる操作、SSE切断は、バックエンドのキュー実行へ
  影響しない。
- ジョブ追加途中のドラフトだけはバックエンドメモリ上の非永続状態である。

## 5. 非対象

- 検索、ソート方式の切替、ブックマーク、履歴
- 設定編集画面
- テーマ切替、アニメーション主体の演出
- スマートフォン、タブレット向けレイアウト
- TUI固有キー操作の再現
