# TUI画面仕様

## 基本方針

- リッチさより運用保守コストの低さを優先する。
- 画面遷移とキー操作は少なくする。
- マウス操作は不要。
- 色やアニメーションは必須ではない。
- ターミナル幅が狭い場合もクラッシュせず、長い文字列を安全に省略する。
- 日本語、空白を含むパスとファイル名を正しく表示・処理する。
- 主操作は矢印キーとし、`Tab`、`Enter`、`Space`、`Esc`も従来操作として残す。
- 一覧とフォームは`↑` / `↓`で移動する。一覧は`→`で決定し、`←`で戻る。
- チェック項目は`←` / `→`または`Space`で切り替える。
- チェック項目上の`Enter`はチェックを切り替えず、「次へ」を実行する。
- 出力名画面の入力欄でも`Enter`は入力を確定して「次へ」を実行する。
- チャプター画面の区切り時間入力欄でも`Enter`は再計算後に「次へ」を実行する。
- キュー追加中の`Esc`は設定を中止してメインメニューへ戻る。
- 入力欄以外の`Backspace`は一つ前の画面へ戻る。
- 文字列・数値入力中の`←` / `→`と`Backspace`は、カーソル移動と文字削除を優先する。

## 1. メインメニュー

```text
ChapterBrake

待機中: 11件

> 新しいジョブを追加
  キュー・実行状況
  終了
```

同じアプリで実行中にも新しいジョブを追加できる。別プロセスの二重起動は拒否する。

## 2. ファイル選択

通常起動では`settings.json`の`input_directory`から開始する。
`--directory PATH`または`-d PATH`付きでは、設定を変更せず、その一回だけ
指定ディレクトリから開始する。カレントディレクトリを指定する場合は`-d .`とする。

```text
入力MKVを選択
現在: /Volumes/2TB HDD/Images

  ../
> Series/
  source-a.mkv      18.4 GiB
  source-b.mkv       7.2 GiB
```

最低キー:

- `↑` / `k`: 上へ
- `↓` / `j`: 下へ
- `→` / `Enter`: ディレクトリへ入る、MKVを決定
- `←`: 親ディレクトリへ戻る
- `Backspace` / `Esc`: メインメニューへ戻る

`../`は先頭へ固定し、それ以外は大文字小文字を区別しない名前昇順で表示する。
一覧表示時にMKVを解析しない。

## 3. 解析結果概要

ファイル決定後に解析し、結果を簡潔に表示する。

```text
source-a.mkv
容量: 18.4 GiB
時間: 2:21:43
チャプター: 24
音声: 3
字幕: 2
```

解析失敗やチャプターなしの場合はログ位置と理由を表示して戻る。

## 4. プリセット選択

最初にChapterBrake内蔵の`My Presets相当`だけを一列で表示する。
HandBrake GUIやGUI設定ファイルは参照しない。検索や階層折り畳みは不要。

```text
> MP4 Presets       1080p MP4・自動クロップ
  MKV Presets       1080p MKV・自動クロップ
  My Old Presets    480p MP4・自動クロップ
  GCCX              480p MP4・クロップなし
  その他のプリセットから選ぶ
```

「その他のプリセットから選ぶ」を決定した場合だけHandBrake標準プリセットの
一覧へ移動する。標準プリセット一覧では`←` / `Backspace`で`My Presets`一覧へ
戻り、`Esc`でメインメニューへ戻る。

コンテナ形式が判定できない、またはMP4/MKV以外のプリセットは選択時に
明確なエラーとする。

## 5. 出力名

```text
出力ベース名: [source-a]
開始番号:      [06]
出力先:        /Volumes/2TB HDD/Movies/<出力ベース名>
```

出力先は表示だけで、初期版では画面から変更しない。

## 6. チャプター選択

```text
区切り時間 (分:秒): [23:40]
[動画全体: 1:34:45] [最終出力: Chapter 019-021 / 23:41（末尾を結合）]
[x] 末尾の短いチャプターを除外 (chapter 024 / 0:01 / 2秒以下は自動)

番号  開始      単体      出力合計  タイトル
[x] 001  0:00      1:32      24:05     Opening
[ ] 002  1:32      22:07     -
[ ] 003  23:39     0:26      -
[x] 004  24:05     1:06      23:40     Part B

[入力した時間の近似値にチェック]
[すべてのチェックを外す]
```

最低キー:

- `↑` / `↓`: 移動
- 区切り時間入力中の`Enter`: 入力値で近似チェックを再計算して次へ
- `←` / `→` / `Space`: チェック切替
- `Enter`: チェックを変更せず次へ
- `Backspace`: 前へ
- `Esc`: メインメニューへ戻る

区切り時間の初期値は`settings.json`から取得し、この画面の変更は今回の
ジョブ追加だけに適用する。近似選択ボタンでは同じ画面で開始位置を選択し直し、
入力欄のEnterでは選択し直して音声画面へ進む。自動選択表示には適用中の時間を
表示する。チャプターを手動変更した後は自動選択表示を解除する。
チェック0件では次へ進めない。

動画全体の長さ、各チャプターの絶対開始時刻と単体時間、各チェック開始位置から
生成される出力区間の合計時間を表示する。自動近似で短い末尾単体出力が生じる場合は、
残りを直前区間へ結合して、最終区間を画面先頭に表示する。

最終チャプターが2秒以下かつ全体が2チャプター以上なら、末尾除外を初期オンにする。
ユーザーは左右キーまたはSpaceで解除できる。末尾行を開始位置としてチェックした
場合も除外を解除する。除外中は最終チャプターをどの出力範囲にも含めない。

## 7. 音声設定

```text
音声トラック

[x] 1  Japanese  AC3  5.1ch
[x] 2  Japanese  AAC  Stereo
[-] 3  Commentary AAC Stereo  初期版では未対応

各選択トラックの出力:
  高品質    AC3 Passthru 5.1ch
  標準品質  AAC Stereo
```

トラック1・2について使用チェックだけを変更できる。ビットレート入力は設けない。
少なくとも一つの入力音声トラックを必須とする。

## 8. 字幕設定

MKVの場合だけ表示する。

```text
字幕

[x] 字幕を入れない
[ ] 1  Japanese  PGS
[ ] 2  English   PGS

焼き付け: 無効
```

「字幕を入れない」と字幕トラックは排他的。複数字幕は選択可能。

MP4の場合はこの画面を省略し、内部的に字幕なし・焼き付けなしを強制する。

## 9. プレビュー

```text
入力: source-a.mkv
プリセット: My H.265 MKV
出力先: /Volumes/2TB HDD/Movies/source-a
出力数: 4

source-a_06.mkv  chapter 1-5    約23:39
source-a_07.mkv  chapter 6-13   約23:42
source-a_08.mkv  chapter 14-17  約23:38
source-a_09.mkv  chapter 18-24  約24:01

入力音声: 1, 2
各入力から: 高品質 AC3 Passthru + 標準品質 AAC Stereo
字幕: 1
焼き付け: 無効
タイトル: 各出力ファイル名のstem
```

既存ファイルがある場合は一覧で警告し、明示承認後だけ追加する。

キューへ追加した時点で、一時停止中でなければエンコードを開始する。

## 10. キュー・実行状況

```text
1. [実行中 37.2%] source-a_06.mkv  handbrake / ETA 12:14 / chapter 1-5
2. source-a_07.mkv  chapter 6-13
3. source-b_01.mp4  chapter 1-8
```

矢印キーは選択だけを移動する。`j`で選択中の待機ジョブを一段下へ、`k`で
一段上へ移動する。実行中ジョブは移動できず、その前へ待機ジョブを移動できない。

Enterで詳細を開く。待機ジョブには削除ボタンを表示し、実行中ジョブには
「現在ジョブ後に一時停止」と「即時中断して一時停止」を表示する。一時停止予約は
取り消せる。停止中の先頭ジョブ詳細には「キューを再開」を表示する。

即時中断では部分出力を削除して現在ジョブを先頭に残し、後続へ進まない。
通常の終了は現在ジョブを完了してから残りを一時停止し、アプリを終了する。
次回起動後は残った先頭ジョブから再開する。同一ジョブの途中再開は行わない。
