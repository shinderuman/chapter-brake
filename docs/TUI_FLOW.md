# TUI画面仕様

## 基本方針

- リッチさより運用保守コストの低さを優先する。
- 画面遷移とキー操作は少なくする。
- マウス操作は不要。
- 色やアニメーションは必須ではない。
- ターミナル幅が狭い場合もクラッシュせず、長い文字列を安全に省略する。
- 日本語、空白を含むパスとファイル名を正しく表示・処理する。
- 主操作は矢印キーとし、`Tab`、`Enter`、`Space`、`Esc`も従来操作として残す。
- 一覧とフォームは`↑` / `↓`で移動する。一覧は`→`で決定し、`←`で戻る。
- チェック項目は`←` / `→`または`Space`で切り替える。
- チェック項目上の`Enter`はチェックを切り替えず、「次へ」を実行する。
- 出力名画面の入力欄でも`Enter`は入力を確定して「次へ」を実行する。
- キュー追加中の`Esc`は設定を中止してメインメニューへ戻る。
- 入力欄以外の`Backspace`は一つ前の画面へ戻る。
- 文字列・数値入力中の`←` / `→`と`Backspace`は、カーソル移動と文字削除を優先する。

## 1. メインメニュー

```text
ChapterBrake

待機中: 11件

> 新しいジョブを追加
  キューを表示
  キューを実行
  終了
```

キューが空の場合は実行を選択不可にするか、空であることを表示して戻る。

## 2. ファイル選択

通常起動では`settings.json`の`input_directory`から開始する。`--cwd`付きでは、
設定を変更せず、その一回だけ起動時のカレントディレクトリから開始する。

```text
入力MKVを選択
現在: /Volumes/2TB HDD/Images

  ../
> Series/
  source-a.mkv      18.4 GiB
  source-b.mkv       7.2 GiB
```

最低キー:

- `↑` / `k`: 上へ
- `↓` / `j`: 下へ
- `→` / `Enter`: ディレクトリへ入る、MKVを決定
- `←`: 親ディレクトリへ戻る
- `Backspace` / `Esc`: メインメニューへ戻る

一覧表示時にMKVを解析しない。

## 3. 解析結果概要

ファイル決定後に解析し、結果を簡潔に表示する。

```text
source-a.mkv
容量: 18.4 GiB
時間: 2:21:43
チャプター: 24
音声: 3
字幕: 2
```

解析失敗やチャプターなしの場合はログ位置と理由を表示して戻る。

## 4. プリセット選択

最初にChapterBrake内蔵の`My Presets相当`だけを一列で表示する。
HandBrake GUIやGUI設定ファイルは参照しない。検索や階層折り畳みは不要。

```text
> MP4 Presets       1080p MP4・自動クロップ
  MKV Presets       1080p MKV・自動クロップ
  My Old Presets    480p MP4・自動クロップ
  GCCX              480p MP4・クロップなし
  その他のプリセットから選ぶ
```

「その他のプリセットから選ぶ」を決定した場合だけHandBrake標準プリセットの
一覧へ移動する。標準プリセット一覧では`←` / `Backspace`で`My Presets`一覧へ
戻り、`Esc`でメインメニューへ戻る。

コンテナ形式が判定できない、またはMP4/MKV以外のプリセットは選択時に
明確なエラーとする。

## 5. 出力名

```text
出力ベース名: [source-a]
開始番号:      [06]
出力先:        /Volumes/2TB HDD/mp4/
```

出力先は表示だけで、初期版では画面から変更しない。

## 6. チャプター選択

```text
[x] 23分40秒近似値にチェック
[ ] すべてのチェックを外す

[x] 001  0:00:00   0:00:00  Opening
[ ] 002  0:01:32   0:01:32
[ ] 003  0:23:39   0:23:39
[x] 004  0:24:05   0:00:00  Part B
[ ] 005  0:25:11   0:01:06
```

最低キー:

- `↑` / `↓`: 移動
- `←` / `→` / `Space`: チェック切替
- `Enter`: チェックを変更せず次へ
- `Backspace`: 前へ
- `Esc`: メインメニューへ戻る

手動変更後は自動選択表示を解除する。チェック0件では次へ進めない。

## 7. 音声設定

```text
音声トラック

[x] 1  Japanese  AC3  5.1ch
[x] 2  Japanese  AAC  Stereo
[-] 3  Commentary AAC Stereo  初期版では未対応

各選択トラックの出力:
  高品質    AC3 Passthru 5.1ch
  標準品質  AAC Stereo
```

トラック1・2について使用チェックだけを変更できる。ビットレート入力は設けない。
少なくとも一つの入力音声トラックを必須とする。

## 8. 字幕設定

MKVの場合だけ表示する。

```text
字幕

[x] 字幕を入れない
[ ] 1  Japanese  PGS
[ ] 2  English   PGS

焼き付け: 無効
```

「字幕を入れない」と字幕トラックは排他的。複数字幕は選択可能。

MP4の場合はこの画面を省略し、内部的に字幕なし・焼き付けなしを強制する。

## 9. プレビュー

```text
入力: source-a.mkv
プリセット: My H.265 MKV
出力先: /Volumes/2TB HDD/mp4/
出力数: 4

source-a_06.mkv  chapter 1-5    約23:39
source-a_07.mkv  chapter 6-13   約23:42
source-a_08.mkv  chapter 14-17  約23:38
source-a_09.mkv  chapter 18-24  約24:01

入力音声: 1, 2
各入力から: 高品質 AC3 Passthru + 標準品質 AAC Stereo
字幕: 1
焼き付け: 無効
タイトル: 各出力ファイル名のstem
```

既存ファイルがある場合は一覧で警告し、明示承認後だけ追加する。

## 10. キュー表示

編集機能は持たせない。

```text
1. source-a_06.mkv  chapter 1-5
2. source-a_07.mkv  chapter 6-13
3. source-b_01.mp4  chapter 1-8
```

表示後に戻るだけでよい。

## 11. 実行画面

```text
実行中 1 / 11
source-a_06.mkv
chapter 1-5
段階: HandBrakeエンコード
進捗: 37.2%  ETA 00:12:14

Ctrl+C: 即時中断
```

実行段階は「HandBrakeエンコード」「タイトル設定」「検証」「最終化」を表示する。進捗の安定取得が難しい場合、初期版は現在ジョブとHandBrakeCLI出力の末尾表示だけでもよい。ただしログは完全に保存する。

`Ctrl+C`はアプリ全体を無処理で落とさず、即時中断手順を実行する。処理終了後にメインメニューへ戻す。
